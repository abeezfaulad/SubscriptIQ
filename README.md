# SubscriptIQ

**Turn subscription chaos into clarity.**

SubscriptIQ is an intelligent subscription management platform designed for both individuals and businesses.

### Core Features
- Subscription tracking and spending insights
- Forgotten and overlapping subscription detection
- Renewal management
- Savings simulator
- B2B subscription and entitlement management
- Role-based workspace access

### Tech Stack
- Next.js
- TypeScript
- Supabase
- PostgreSQL

### Project Status
Developed as a hackathon project.
